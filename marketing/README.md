# Marketing

Research and plans for publishing and growing Miles Pro Sync. Written so a future Claude session can
re-read it as context: start with this file, then the one you need.

| File | Contents |
|---|---|
| `competitor-research.md` | Competitor free tiers, prices, complaints (web research, with sources) |
| `positioning-and-aso.md` | Positioning statement, differentiators, App Store keyword plan |
| `launch-and-growth-plan.md` | App Store publishing checklist, growth levers, metrics |
| `app-store/listing.md` | Draft App Store copy: name, subtitle, keywords, description, captions |
| `banners/` | Web banners in 8 sizes (HTML + PNG) and the generator |

## Ground rules for editing
- Every competitor figure needs a source and a "last checked" date. Sources conflict; say so.
- Hypotheses (keyword ideas, positioning) are marked as such until validated with real data
  (App Store rankings, Apple Search Ads, AppTweak/Sensor Tower).
- Keep the claim "repeat routes classify themselves" in line with the code
  (`TripRecorder.applyPreviousClassification`); test its accuracy before advertising it.
- Tax claims: say "estimates", "not tax advice".
